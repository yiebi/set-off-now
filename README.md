# 现在就出发（Set Off Now）

## 项目简介
本项目是一款微信小程序雏形，面向用户提供社区互动功能，包含首页展示、消息通知、点赞回复、个人中心、家乡模块等，界面清新简洁，交互流畅。

## 技术栈
- 前端：微信小程序原生框架 WXML / WXSS / JavaScript
- 后端：微信云开发（云函数 + 云数据库）
- 开发工具：微信开发者工具

## 功能模块
- 首页
- 登录 / 注册
- 消息通知（回复、点赞、系统通知）
- 个人中心
- 家乡模块

## 使用说明
1. 将源码导入微信开发者工具
2. 在云开发环境中部署云函数并关联数据库
3. 编译预览即可体验
